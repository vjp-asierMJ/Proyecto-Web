## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3** – Estructura y diseño responsive  
* **JavaScript (ES6+)** – Lógica y carga dinámica de contenido  
* **Fetch API** – Consumo de datos JSON para servicios  
* **Squoosh** – Optimización de imágenes a formato WebP  
* **Formspree** – Gestión de formularios de contacto  
* **Google Fonts** – Montserrat, Inter y Open Sans  
* **FontAwesome / Lucide Icons** – Iconografía lineal para servicios  

---

## 📈 Fases del Proyecto

### Fase 1: Identidad y Maquetación

- **Personalización de Plantilla:** Implementación de variables CSS (`:root`) según la guía de estilos de EcoPulse Dynamics.
* **Optimización de Imágenes:** Sustitución de todas las imágenes por versiones `.webp` de alta eficiencia.
* **SEO:** Configuración de meta-tags, título y favicon personalizado.
* **Responsive Design:** Adaptación completa para desktop, tablet y móvil.

### Fase 2: Interactividad y Datos

- **Carga Dinámica de Servicios:** Los servicios se cargan desde `servicios.json` usando Fetch API para facilitar mantenimiento futuro.
* **Validación de Formulario:** Validación de email y longitud mínima del mensaje.
* **Integración de Formulario:** Conexión con backend real para la recepción de leads.
* **Hover Effects y Animaciones:** Botones y tarjetas con transiciones suaves y escalado (scale 1.05).

## 🌱 Servicios de EcoPulse Dynamics

* **Solar Modular:** Paneles solares para fachadas verticales y soluciones urbanas.  
* **V2G (Vehicle-to-Grid):** Estaciones de carga que devuelven energía a la red doméstica.
